# 整书理解：密码函数的安全性指标分析

李超、屈龙江、周悦，科学出版社，2011，ISBN 978-7-03-030008-9。用户指定扫描 PDF 共286页；正文书页p对应PDF第p+10页（已核书p1、p2及目录）。

## 结构
本书按目标指标组织七章：基础表示和Walsh/RM（1—20）；PN（21—71）；APN（72—104）；Bent（105—127）；几乎Bent（128—147）；弹性（148—199）；最优代数免疫度（200—末章参考文献）。各章依次联结定义、性质、构造、等价性或计数及应用。

## 解释
前言将差分均匀度、非线性度、相关免疫阶和代数免疫度联结到相应攻击模型。研究任务应先确定攻击与函数类型，再用定义或定理检查候选。不能把一个单项指标最优等同于完整密码安全。标量和向量函数需要区分；向量性质往往涉及全部非零分量。
